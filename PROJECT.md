# Project: Skillens Recruitment Workflow

## Architecture
- Backend: FastAPI, SQLAlchemy (SQLite), Celery (Background tasks).
- Frontend: Next.js (React), Tailwind CSS.
- The system handles candidate registration, AI-driven assessment tracking, interview scheduling with AI recommendations, and multi-tier company roles.

## Milestones

| # | Name | Scope | Dependencies | Status |
|---|------|-------|-------------|--------|
| 1 | Multi-Tier Accounts & Job Limits | Backend: Sub-account creation logic, parent-child (admin/recruiter) permissions, Job posting deadline enforcement. Frontend: UI for managing sub-accounts and setting job deadlines. | none | PLANNED |

| 3 | Interview Scheduling & AI Recs | Backend: Interview models (1-2 day distance enforcement), Candidate accept/reject endpoints, HR recommended slots logic based on quotas. Frontend: Candidate & HR UI for scheduling. | M2 | PLANNED |
| 4 | AI Interview Questions & Scoring | Backend: Deriving questions from assessment results, storing HR final scores, final ranking update logic. Frontend: HR dashboard displaying AI questions, post-interview scoring UI. | M3 | PLANNED |
| 5 | E2E Testing Suite | Comprehensive E2E test suite covering all tiers. Generated by the Testing track. | none | PLANNED |
| 6 | Final E2E Run & Harden | Pass all E2E tests, then run adversarial coverage hardening. | M1, M2, M3, M4, M5 | PLANNED |

## Interface Contracts
### General
- Standard REST API JSON responses.
- Backend running on port 8000.
- Frontend running on port 3000.

## Code Layout
- `backend/`: FastAPI application code (routers, schemas, models, services).
- `frontend/`: Next.js application code (src/app, src/components, src/lib).
- `.agents/`: Agent coordination files.
